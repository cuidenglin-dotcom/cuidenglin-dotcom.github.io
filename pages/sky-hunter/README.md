# 天空猎手 · 老鹰抓鸽子

独立静态网页游戏，入口为 `/pages/sky-hunter/`。无需构建、服务器程序或外部字体服务。

- 每局 60 秒，最后 3、2、1 秒各响一声提示。
- 一只可拖动老鹰、三只鸽子；轻点释放瞬间火圈，每命中一只得 1 分。
- 8 层难度，随难度增加速度、变向和闪避能力。
- 开局输入玩家名字，最多 12 个字符；成绩按难度显示前 5 名。
- 排行榜使用浏览器 localStorage，同一浏览器与站点保留记录，不跨设备、跨域同步。
- 姓名、分数保存在本机，不发送到服务器；无姓名的旧纪录显示“未署名玩家”。
- 游戏左上区域的“网站首页”链接返回站点首页。

## 维护

源文件在本机 `C:/codex/eagle-game/`。发布时只需要本目录的 index.html、style.css、game.js 和此说明文件；不要上传测试输出、服务器日志或临时文件。

GitHub 用提交历史回滚；VPS 发布前备份首页与维护说明。修改资源后更新 HTML 中的资源版本号以避免浏览器缓存。
